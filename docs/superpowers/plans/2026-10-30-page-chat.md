# Page Chat Implementation Plan

**Goal:** Make pi-x useful on any readable web page, with persistent page conversations and X writing as an explicit capability.

**Architecture:** Keep the existing X adapter and durable job runner. Add standalone conversation records and immutable context snapshots to chat jobs, and a chat mode in the shared harness and panel. Conversation selection belongs to a browser window and never follows navigation implicitly.

**Tech stack:** TypeScript, Chrome MV3, Pi Durable, Vitest, Playwright.

**Spec:** docs/PRODUCT-SCOPE.md

## Constraints and review focus

Preserve existing uncommitted work and X behavior. Page content is untrusted. Never silently attach another tab. Missing metadata stays absent; extraction limitations are visible. Closing a tab must not end page chat. Clear/delete must remove chat records and durable history. Current-page capture may use HTTP(S), while research URL restrictions stay unchanged.
